# Question 1 

### Based on the instructional videos, what are the key steps for managing files between Google Colab and GitHub? 

The connection between Google Colab and Github require a few important steps. First a Repo should be initialized in Github with the folders for each assignment. Then on Google Colab a Juypter Notebook is created which runs the code blocks. Then this Notebook is saved in Github by navigating File>Save A Copy In Github and the file path is specified. Aditionally code can be stored locally for development by checking out a github repo into VS Code.
